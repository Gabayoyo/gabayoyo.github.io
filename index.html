mlir-match

An out-of-tree MLIR dialect for pattern matching optimisations.

mlir-match provides a pattern-matching dialect capable of representing functional pattern matching as operations in MLIR, allowing for potential match-specific optimisations to be performed. The repo showcases this potential through the application of Maranget's Algorithm, reducing the number of comparisons each match has to perform in order to pick the right case.

mlir-mracle

A metamorphic testing harness for OpenMP concurrency in MLIR.

Developed as part of the MLsystems Research Internship, mlir-mracle is a metamorphic testing framework for MLIR's OpenMP dialect. By fuzzing OpenMP programs and applying metamorphic relations, it aims to detect concurrency bugs in the MLIR compiler. So far, one verification bug has been found and fixed in MLIR's OpenMP dialect, thanks to mlir-mracle.

ScaIR IR Interpreter

An extensible MLIR-SSA interpreter developed within ScaIR.

The ScaIR IRinterpreter handles all aspects of interpretation automatically, abstracting away the complexity of implementation and allowing for the easy addition of operation and dialect interpretation logic for developers. Achieves 12-18x speedup for large programs over xDSL's existing interpreter infrastructure.

RISC-E

A simulated cost harness for prototyping RISC-V hardware.

RISC-E provides an interface for defining and simulating RISC-V hardware components in C++. Through the RISC-V ELF interpreter, the harness can then compares multiple implementations of the same component, in terms of simulated performance metrics such as CPI and cycles saved.

BiggerBrother In progress

A computer vision tool for gym training.

Provides computer vision analysis of a recorded weightlifting set, returning metrics such as per-rep velocity, range of motion and rep timings. Also features the first ever proximity to failure estimator software. Features CI pipeline with mypy, pytest (100+ tests) and ruff linting. Hosted website WIP.
